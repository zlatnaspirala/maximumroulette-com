matrix-engine-wgpu

Cross-Platform Rust Graphics Architecture

The matrix-engine-wgpu is Nikola Lukic's lightweight, pure Rust graphics platform built entirely on top of the cross-platform WebGPU backend interface (wgpu-rs). Operating as a system orchestration engine, it abstracts pipeline instantiation, GPU shader bindings, and vector math routines.

Core Architecture Features

  • Native Rust Safety: Leverages strict type-safety, absolute memory layouts, and thread safety to map raw matrices straight to high performance rendering grids.
  • Platform Portability: Compile target maps flawlessly to native client displays via Vulkan, Metal, DX12, or run browser setups using WASM over safe WebAssembly binds.
  • Dynamic Pipeline Orchestration: Simplifies command pipelines, render layers, bind groups, vertex state setup, and frame-pass execution with minimalistic boilerplate.
  • Custom WGSL Integration: Supports WebGPU Shading Language natively, enabling user-defined matrix loops and shaders to communicate in parallel with modern hardware.

Quick Setup & Code Usage

Defining an active rendering app runtime inside a client container is minimal. Add the cargo dependency to your cargo configurations and spin up the engine instance: 

[dependencies]
matrix-engine-wgpu = { git = "https://github.com/zlatnaspirala/matrix-engine-wgpu" }
wgpu = "22.0.0"

And initialize your native graphics stage with clean Rust definitions: 

use matrix_engine_wgpu::{EngineInstance, GraphicsStage};

fn main() {
    let mut instance = EngineInstance::new()
        .with_title("WebGL & WGPU Matrix Space")
        .with_dimensions(1280, 720);

    // Boot real-time rendering loop
    instance.run(|stage, render_pass| {
        // Core pipeline transformations and drawing updates
        stage.clear_color(0.05, 0.05, 0.07, 1.0);
    });
}

Designed to function as a modular, hardware-level container for 3D physics, real-time particle structures, and complex matrix transforms. It facilitates the immediate porting of traditional algorithms from WebGL to pure GPU performance targets.
